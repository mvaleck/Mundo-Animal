  <h1>🐾 Mundo Animal </h1>
    <p>
      Um site educativo e visualmente atrativo sobre o reino animal, desenvolvido com o objetivo de praticar meus conhecimentos em HTML, CSS e JavaScript puro.
    </p>

  <h2>📚 Sobre o Projeto</h2>
    <p>
      Este projeto foi criado como parte do meu aprendizado em desenvolvimento web. A ideia principal era construir um site informativo com foco em:
    </p>
    
<ul>
  <li>Organização de conteúdo educacional</li>
  <li> Estilização com CSS para uma boa apresentação visual </li>
  <li> Manipulação do DOM com JavaScript para dar mais interatividade </li>
</ul>

<h2>🐾 Conteúdo Educativo</h2>
<p>
  O site apresenta informações sobre diferentes classes de animais, incluindo:
</p>

<ul>
  <li>🐒 Mamíferos</li>
  <li>🐦 Aves</li>
  <li>🐜 Insetos</li>
  <li>🐍 Répteis</li>
</ul>

<p> O objetivo é oferecer um conteúdo simples e acessível para quem deseja aprender mais sobre esses animais. </p>

<h2>🛠️ Tecnologias Utilizadas</h2>

<li>HTML5</li>
<li>CSS3</li>
<li>JavaScript (puro, sem frameworks)</li>

<h2>🚀 Como Rodar o Projeto</h2>

<ol>
  <li> Clone este repositório com o comando:</li>
<p> git clone https://github.com/seu-usuario/mundo-animal.git</p>

<li> Acesse a pasta do projeto:</li>
<p>cd mundo-animal</p>

<li> Abra o arquivo index.html no seu navegador.</li>
</ol>

<p>Ou, se preferir, utilize uma extensão como o Live Server no VS Code para rodar localmente.</p>
